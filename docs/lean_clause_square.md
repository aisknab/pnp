# Strict CNFSAT as an affine binary square

For each strict input bitstring, the construction produces binary square matrices whose entries depend affinely on the original assignment bits. A particular correctly sized assignment satisfies the input formula exactly when its selected matrix has a nonzero kernel vector. The assignment in this statement is the original numbered word, not a separate choice per clause.

The [numbered interface](../lean/PNP/ClauseSquare/Numbered.lean) gives both the existential equivalence (`strict_all_numbered`) and the stronger same-word equivalence (`strict_same_mask_word`). The [column action](../lean/PNP/ClauseSquare/Packed.lean) XORs precisely the input-selected binary slope columns with the constant columns. Both the original assignment and the nonzero kernel vector have checked widths; an unused high bit is not a witness.

The auxiliary rows start at one, multiply by the failure value of each in-range literal, and use XOR at the end of a clause to keep the accumulator exactly when that clause is satisfied. The prefix determines every auxiliary value from the assignment and the final tag. In a nonzero kernel vector the tag has to be one. Thus checking each row with a different vector would be unsound. An empty conjunction is true, an empty clause is false, literals outside the declared width are false in either polarity, and malformed source words give the nonsingular one-by-one identity.

The [size theorem](../lean/PNP/ClauseSquare/Size.lean) gives the dimension as two plus the number of clauses and the number of in-range literal occurrences. Each packed coefficient column fits in that many bits. For a source of length `L`, the [unframed coefficient table](../lean/PNP/ClauseSquare/PayloadSize.lean) has exactly `(n+1)d²` bits and at most `(L+1)³` bits, including on malformed input. This table alone needs its dimensions `n` and `d` to be read.

The [standalone target](../lean/PNP/ClauseSquare/Framed.lean) therefore prefixes the table by `n` ones and a zero, then `d` ones and a zero. It reads the constant matrix first and then the `n` slope matrices, column by column, with row zero first. Decoding requires exactly the specified payload length and rejects extra bits. The full word has length at most `(L+1)³ + 2L + 3`. In a zero-dimensional bank there is no nonzero kernel vector.

For every source `s`, `PNP.ClauseSquare.Framed.strict_iff_target` proves `CNFSAT s ↔ accept (emit s) = true`. The acceptor reads **only its target bitstring**. It exhaustively enumerates the bounded masks; the absence of syntax or hidden source premises is a semantic guarantee, not an efficient search method.
The construction does not supply a polynomial-time method of finding a singular assignment, prove the runtime of a concrete machine, or establish that CNFSAT is in P. No new weighted proof checkpoint follows from this representation. See the [separate proof and coverage ledger](../status/PROOF_PROGRESS.json).
