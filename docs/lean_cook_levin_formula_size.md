# External Cook–Levin encoded-formula size

`lean/PNP/Concrete/CookLevinFormulaSize.lean` bounds the actual canonical
unary-indexed CNF bitstring generated by the concrete Cook–Levin development.
The bound is fixed by one `PolynomialTimeVerifier` and is evaluated only at
the external source-input length.

The file first proves exact token and bit lengths for `encodeCNF`. A literal
with variable index `i` costs `i + 2` tokens, a clause adds its separator and
terminator, and the final bit encoding has the exact length stated by
`PNP.Concrete.CookLevin.encodeCNF_size_exact`.

The local-CNF layer then receives an explicit size discipline. Every concrete
constraint family used by the whole tableau is proved to satisfy it. The
proof covers row shape, control transitions, untouched-cell preservation,
input-only initialization, paired certificate-bit and unary-length
initialization, and final acceptance.

For a fixed verifier, the external polynomials account for:

- encoded verifier input `E(m)`;
- substituted raw execution fuel `F(m)`;
- time rows `T(m) = F(m) + 1`;
- the complete symmetric tape window `W(m)`;
- the fixed compiled-machine state bound `S`;
- Boolean variables `V(m)`;
- local constraints `P(m)`;
- emitted clauses `Q(m) = P(m) * (1 + V(m)^2)`;
- per-clause token cost `R(m) = 2 + (V(m) + 4) * (V(m) + 1)`; and
- the final canonical bit bound
  `O(m) = 2 * ((V(m) + 1) + Q(m) * R(m) + 1) + 1`.

The exported endpoint is:

```lean
theorem PNP.Concrete.CookLevin.VerifierTableauProblem.encodedFormula_size_le
    {language : Language}
    (problem : VerifierTableauProblem language) :
    BitString.size problem.encodedFormula ≤
      (encodedFormulaSizePolynomial problem.verifier).eval
        (BitString.size problem.input)
```

The complete 108-declaration audit reaches only the approved Lean standard
axioms `propext` and `Quot.sound`; it reaches no project assumption and no
choice axiom. Regression checks instantiate both verifier input modes at
empty, one-bit, odd, and even inputs and pin exact codec edge cases.

This milestone does not provide a raw finite machine that constructs the
formula, does not prove a formula-construction runtime polynomial, and does
not package a concrete `PolynomialReduction`. CNFSAT NP-completeness, CNFSAT
in P, `PNP.Main.p_eq_np`, and publication activation remain absent.
