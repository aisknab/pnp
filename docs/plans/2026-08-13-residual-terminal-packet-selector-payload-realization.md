# Residual terminal Packet selector source-payload realization plan

## Legacy anchor

Pinned manuscript Sections 13--14 require a selector interface to reach an
actual payload before the later gain-or-blocker realizer can operate. The
preceding milestone gives every exact grouped-footprint selector one canonical
fail-closed code, but its result stops at a handle and the retained payload
evidence is propositional.

## Unbounded abstraction

Work over every arbitrary finite explicit grouped BN6 family and arbitrary atom
and payload types. Use the decoded input-relative handle to select from the
actual supplied family, without fixing a carrier cardinality, selector count,
sample atom type, or sample payload type.

## Exact theorem boundary

Define a total fail-closed function that maps each accepted canonical code to
the exact original grouped cell and a canonical first original positive payload
atom. Prove rejection equivalence with the decoder, canonical source and input
soundness of every result, exact equivalence with the finite payload-selector
predicate, and preservation of the pair, positive balanced-triple, and
full-span Packet alternatives.

## Remaining downstream blockers

The result is a lookup relative to the supplied explicit grouped family. The
bits still encode only its unary list position and do not serialize atom or
payload data. The milestone does not construct the manuscript's replacement-
circuit gain-or-blocker realizer, prove selector faithfulness or compatibility,
return a gain or typed blocker route, derive or group BN6 survivors, bound the
selector family by encoded circuit size, prove polynomial generation/runtime,
complete PkgC, ZeroSlack, or PCCMin, put CNF-SAT in P, remove a project
assumption, or prove `P = NP`.

## Required evidence

- Lean theorem module over arbitrary finite grouped families.
- Axiom audit whose expected declaration count is derived from the source.
- Generic regression covering exact source selection, fail-closed behavior,
  canonical input recovery, positive payload retention, predicate equivalence,
  and every Packet branch.
- Hostile JavaScript audit rejecting invented cells or atoms, weakened
  rejection/canonicality, fixed bounds, missing branch coverage, and overclaims.
- Synchronized theorem inventory, publication map, status payloads, report,
  documentation, and durable read-only workflow checks.
