# Canonical Packet charge-route reflection milestone

## Objective

Remove the caller-controlled `chargeChecked` bit at the Packet selector
faithfulness boundary. Every canonical handle already selects one original
payload atom whose positive mass is part of the grouped-family structure.
The active Packet/HB endpoint must reflect that internal positive-source-charge
fact by construction while retaining canonical source-route, finite-rank, and
ten-coordinate residual-descent computation.

## Dependency edge

```text
positive BN6 Packet
  + canonical input-relative handle
  + original source atom with strictly positive mass
  + authoritative per-handle finite rank
  + supplied before/after residual ranks
  + executable selector silence and HB active-dependency closure
  -> one exact earliest Packet failure
  -> never charge, exactRoute, or rank
  -> either one of six unresolved semantic-field routes
     or proof that the supplied transition is not RankWF-decreasing
```

The construction is uniform over arbitrary finite grouped BN6 families and
arbitrary finite selector-rank carriers. No fixed carrier, route fixture, or
coordinate bound earns milestone credit.

## Exact theorem boundary

Define

```text
payload.withComputedChargeExactRouteRankDescent expectedRank before after
```

by applying the existing exact-route/rank/descent projection and replacing
`chargeChecked` with `true`. At the canonical grouped-family boundary, the
replacement is justified by

```text
0 < (family.packetSelectorPayloadAtom handle).mass
```

The named endpoint is

```text
PNP.DirectWire.terminalBN6_packet_charge_reflected_hb_first_route_failure
```

It returns an exact first route and `FailureAt` proof, excludes `.charge`,
`.rank`, and `.exactRoute`, and proves that a final `.descent` route
carries actual nondecrease.

## Conservative claim boundary

The reflected fact is only that the selected source atom has strictly positive
mass. It is not the full external charge-surplus theorem, a replacement-circuit
construction, a budget proof, selector compatibility, or an exact minimum.

The six earlier Boolean fields remain supplied and their external manuscript
semantics are not established. A remaining route is still an exact
Boolean-field failure rather than a complete global outcome.

This milestone does not construct the grouped family, rank map, exhaustive
realizer claims, blocker tables, or no-lower ledger; establish complete route
silence, unconditional HB negative closure, ZeroSlack, or PCCMin; prove
encoded-size or polynomial-runtime bounds; put SAT in P; remove a project
assumption; or prove P = NP.
