# M218: Cook-Levin physical dispatch schedule

## Selection rationale

M216 proves complete semantic iteration of every canonical post-header
schedule opportunity. M217 proves one fixed physical machine handles the full
five-symbol optional-token request alphabet, including padding, with exact work
and compiled traces. The next safe dependency is to establish that M217's
physical contract composes over the complete canonical schedule and remains
polynomial in aggregate before attempting the materially harder raw request
selector or one-machine loop.

## Unbounded abstraction

Range over every concrete polynomial-time verifier, every raw source input,
every canonical post-header coordinate, and arbitrary exterior workspace. A
total recursion must apply M217's exact optional-token output action at each
bounded coordinate. Every recursive prefix must agree with the canonical
emitted prefix, and the final output must be the complete encoded CNF token
stream.

For each coordinate, expose M217's exact work-machine execution, compiled
six-for-one execution, and one-step-short nonhalting evidence using the
recursive source and target prefixes. Sum every exact dispatch cost and prove
one verifier-derived source-size polynomial bound. Retain M214's physical
all-coordinate route-classifier evidence without claiming a tape-to-tape
handoff that has not been constructed.

## Exact theorem boundary

Add `PNP.Concrete.CookLevin.BuilderPhysicalDispatchSchedule` and the public
endpoint:

```text
PNP.Concrete.CookLevin.BuilderPhysicalDispatchSchedule.cook_levin_builder_physical_dispatch_schedule_checked_complete
```

The endpoint takes only a `VerifierTableauProblem` and proves:

1. recursive physical-dispatch output at the body-slot count equals the exact
   encoded formula token stream;
2. every coordinate and arbitrary exterior has the exact M217 work, compiled,
   and one-step-short trace against the recursive prefix invariant;
3. every embedded coordinate retains M214's physical classifier contract; and
4. aggregate compiled dispatch work is bounded by one source-size polynomial.

No coordinate, token, request, trace, schedule, classifier result, or success
certificate is supplied to the endpoint.

## Downstream blockers preserved

M218 does not construct the physical request cell from M214's raw classifier.
It does not connect each final tape directly to the next initial tape or
implement one literal raw-machine loop. It therefore does not complete the raw
formula builder, establish builder `FunctionProgram.RawRefinement`, package the
Cook-Levin `PolynomialReduction`, establish CNFSAT NP-hardness or
NP-completeness, put CNFSAT in P, close a global gate, create the eligible root
theorem, or prove P = NP.

The fixed risk-weighted score remains 35 percent with the 20 to 40 percent
uncertainty range. Formal artefact coverage is regenerated separately.
