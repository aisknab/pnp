## Causality and rank argument

Prove general open-evaluation prefix causality. Values at original gates before
a cutoff are unchanged when boundary valuations agree on primary inputs and
external gate wires before that cutoff. Use the actual open program evaluator.
Whole-circuit induced valuations are insufficient because an external gate may
not realize both Boolean boundary values in complete executions.

For a sole external boundary gate b, earlier selected gates therefore have
equal false and true open values. The literal source-derived minimum word
must represent those early observations as constants. It must not retain an
input or NOT dependency just because an equivalent supplied program could.

consumers cannot reference the boundary input or NOT because their selected
producers realize to constants. The NOT itself depends only on b. Empty and
primary-input boundary cases can reuse established primary-boundary acyclicity.

zero-gate branch and its single shared NOT branch, not an arbitrary semantically
equivalent replacement.
