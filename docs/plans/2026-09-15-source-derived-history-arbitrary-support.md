   exterior(j) = (j+1)*(R+1) and replacement(k) = level(k)*(R+1)+(k+1).
   Every actual edge decreases this rank. Therefore the existing literal
   compiler computes a topological order for every successfully closed history.

```text
final physical gates + actual history removals
```

compilation stage adds no rejection beyond the source history compiler.
