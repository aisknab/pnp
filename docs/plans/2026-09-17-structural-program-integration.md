## Remaining limitations and publication decision

This checks offered complete computational programs; it does not discover a
successful certificate for every input. Full manuscript profiles, remaining
normalization/materializer rules, VerifyDW, ChargeSoundness and Package E remain
open. The route still needs terminal-derived families, global routing,
unconditional SaturatePositive, BCELReady and ZeroSlack, complete exact PCCMin
and encoded-input polynomial runtime/output/certificate bounds.

No fixed weighted progress checkpoint or global gate closes. Formal artefact
coverage may change only after the publication row is earned. No proof-completion
credit follows from the additional declarations, examples or tests.

Default publication decision: defer PNPLabs while this integrates a bounded
computational component without changing the public global-proof bottom line.
Reassess only if the completed general capability materially changes that bottom
line; accumulated row counts alone are not a publication trigger. Keep the
currently published website's source pin and coherent values unchanged meanwhile.
